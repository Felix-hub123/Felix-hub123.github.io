Projeto em destaque

LisAeroGest

Plataforma de gestão aeroportuária composta por aplicação Web, API REST e aplicação Mobile.

LisAeroGest
Sistema de Gestão Aeroportuária

Web, API e Mobile numa solução integrada.

O LisAeroGest centraliza processos relacionados com voos, passageiros, bilhética, check-in, gates, notificações e operações aeroportuárias.

O sistema disponibiliza experiências diferentes para Administrador, Funcionário e Passageiro.

01

ASP.NET Core MVC Gestão operacional e administrativa.

02

REST API + JWT Comunicação segura com aplicações externas.

03

.NET MAUI Experiência mobile para passageiros e operações.

04

PostgreSQL + EF Core Persistência de dados e regras de negócio.
